# 地图模块化环境素材记录 V8

更新时间：2026-07-30

## 本轮决定

墙体不再使用混杂的 AI 接触表。正式结构套件以 `48×48` 为单元，墙带几何宽度固定为 `16px`，通过 `N/E/S/W` 连接掩码组合横墙、竖墙、转角、T 口和十字口。

## 正式产物

- `prison_wall_kit_48_v1.png`：8×6 墙体图集，只有 34 个可选结构块。
- `prison_wall_kit_preview_v1.png`：透明墙体图集预览。
- `cell_block_a2_wallkit_preview_v1.png`：墙体实际叠加地板后的地图预览。
- `prison_modular_props_48_v1.png`：按母图实际 9×9 网格重新切割的透明小装饰图集；大型跨格装饰后续改为独立场景。

## 验收规则

1. 横墙、竖墙、转角、T 口和十字口的墙带宽度均为 16px。
2. 转角必须同时连接两个方向；T 口必须同时连接三个方向。
3. 所有连接边必须到达 48px 单元边缘，不能出现透明缝、黑缝、台阶或厚度跳变。
4. 墙体结构与灯具、管线、终端分层；装饰不得携带墙体背景。
5. `audit_prison_tileset.gd` 必须通过：结构 34 格、装饰 81 格、四角与五种连接口几何验收通过。
